# 행성 지표 탐험 — 설계

## 1. 한 판의 흐름 (2~3분)

1. 행성 곁에서 **「착륙 탐사」** 버튼(아이콘 `act_land`)을 누른다. 가스 행성은 착륙할 수 없다(버튼 대신 "가스 행성 — 착륙 불가" 안내).
   해금: 식민지가 하나라도 있으면(어느 항성계든, 또는 `sector > 0`). 해금되면 처음 행성 곁에 갔을 때 미나(조언자)가 한 번 알려 준다.
2. 소개 카드: 행성 이름·종류, 이 행성에서 이미 찾은 발견(광맥·둥지 소탕·완전 탐사), 오늘 남은 "온전한 보상" 횟수, 규칙 세 줄
   ("지점을 찾아 조사", "산소가 다 되기 전에 착륙선으로", "격추되면 전리품 절반").
3. 탐사: 착륙선 옆에서 탐사 차량으로 시작. 지도는 약 2600×2600 사각 영역(벽으로 막힘). 조작은 본 게임과 같다(조이스틱, 자동 사격, 미사일, 방어막, 부스트).
   - **산소 150초**. 30초 남으면 경고와 함께 착륙선 방향 화살표가 나오고 생물이 몰려온다(압박).
   - 착륙선 반경 안에서 **「귀환」**을 누르면 전리품 100%로 끝난다. 언제든 귀환할 수 있다.
   - 산소가 다 되면 비상 귀환: 전리품 50%. 차량이 파괴되면 50%.
4. 결과: 얻은 크레딧·광석, 새 발견, 유물, 남긴 비율. 「다시 착륙」은 없다(행성 곁에서 다시 누르면 된다). 「돌아가기」.

## 2. 지도

- 같은 행성은 늘 같은 지형: 시드 = `(main.seed, sector, planetIndex)`. 영구 발견(광맥·둥지)은 저장값으로 판단한다.
- 행성 종류별 지형(정원·사막·얼음·용암):
  | 종류 | 바닥 | 장애물 | 위험 지대 |
  |---|---|---|---|
  | 정원 | 초록 이끼·풀 | 거대 버섯·바위 | 포자 늪: 초당 피해 작음 + 감속 |
  | 사막 | 모래·바위판 | 사암 기둥 | 유사(流沙): 큰 감속 |
  | 얼음 | 눈·얼음판 | 얼음 결정 | 냉기 분출구: 감속 + 작은 피해 |
  | 용암 | 검은 현무암 | 화산암 | 용암 웅덩이: 큰 피해 |
- 장애물: 원형 충돌체 25~40개(차량·생물·탄 모두 막힘, 탄은 맞으면 사라짐). 지점·착륙선 주변 260 안에는 두지 않는다.
- 위험 지대: 원형 6~10개. 들어가면 효과, 화면에 그 행성 색으로 표시.

## 3. 탐사 지점 (한 판에 5곳)

| 지점 | 개수 | 하는 일 | 보상 |
|---|---|---|---|
| 유적 | 2 | 반경 안에 **4초** 머물면 발굴(진행 막대, 벗어나면 멈춤). 발굴 시작 때 생물 3~4마리가 몰려온다 | 크레딧 + 유물 확률 35%(유적 3번 연속 꽝이면 다음은 확정). 아직 없는 유물 중에서 |
| 추락선 잔해 | 1~2 | 닿으면 화물 상자 열림(1초) | 크레딧 + 광석 |
| 에일리언 둥지 | 1 | 고정 구조물(체력 있음, 탄·미사일로 파괴). 살아 있는 동안 6초마다 기어다니는 생물 2마리를 낳는다(최대 8) | 광석 많이 + **영구: 둥지 소탕** |
| 희귀 광맥 | 1 | 반경 안에 **3초** 머물면 채굴 | 광석 + **영구: 광맥 발견** |

- 지점은 지도에 아이콘·이름으로 보이고, 화면 밖이면 가장자리 화살표(기존 `_paintOffscreenArrows`와 같은 방식). 끝낸 지점은 흐리게.
- 영구 발견을 이미 한 행성에도 둥지·광맥은 나온다(전리품은 다시 준다). 영구 효과는 중복되지 않는다.

## 4. 생물 (적)

- 기존 적 엔진(`Pirate`)을 그대로 쓰고 그림만 바꾼다. 세 종:
  - **기는 것**(`crawler`): 빠른 근접 — 엔진의 `scout` 동작
  - **침 뱉는 것**(`spitter`): 원거리 — `sniper` 동작
  - **덩치**(`brute`): 느리고 단단함 — `raider`(용암 행성은 `juggernaut`) 동작
- 시작 때 지도 곳곳에 8~12마리 배회. 둥지·유적 발굴·산소 30초 경고 때 추가.
- 강도는 메인 월드의 현재 항성계 배율(`enemyHpMul`, `enemyDamageMul`)을 진입 때 그대로 가져온다.

## 5. 선장 능력치

균열 런과 반대로 **실제 강화·함선·승무원·명예 능력치를 그대로 쓴다**(진행의 보상이 체감되게). 메인 월드에서 진입 때 값을 읽어 둔다.
메인 월드 상태는 정산(§6) 말고는 바꾸지 않는다. 탐사 중 격추 통계·업적·젬·임무는 쌓이지 않는다(도감 적 항목도 안 쌓음 — 생물은 도감 '적'이 아니다).

## 6. 보상과 정산

- 크레딧·광석은 메인 월드 `sectorMul`·`rewardMul`을 곱한다. 기준값은 한 판(귀환 100%)에 본 게임 같은 항성계 약 2분 수입 정도가 되게 잡고, 테스트로 고정한다.
- 하루 온전한 보상 3회(로컬 날짜, `profile.stats`의 `srfDay`/`srfRuns`). 4회째부터 크레딧·광석 30%. 영구 발견·유물은 횟수와 상관없이 준다.
- **완전 탐사**(한 판에 5곳 모두 끝내고 귀환, 행성당 처음 한 번): 젬 3개 — `profile.earnGems('play', …)`만 쓴다(서버 하루 상한에 포함). 영구 표시 `surveyed`.
- 영구 발견 효과(그 행성 식민지에 적용, 식민지가 없으면 정착하면 적용):
  - **광맥 발견**: 광석 생산 `+0.4/초 × 식민지 레벨`(광석이 없던 정원·가스형에도 생김). 원격 수입 저장값(`io`)에도 반영.
  - **둥지 소탕**: 식민지 방어막 최대치 ×1.25.
  - **완전 탐사**: 크레딧 생산 ×1.10.
- 정산은 타이틀이 아니라 **게임 중**에서만 들어오므로 메인 월드에 바로 넣고 저장한다.

## 7. 그림 (오케스트레이터가 Gemini로 만든다, 256×256 투명 PNG, 위쪽이 앞)

`assets/sprites/`: `srf_rover`, `srf_lander`, `srf_crawler`, `srf_spitter`, `srf_brute`, `srf_nest`, `srf_ruin`, `srf_wreck`, `srf_vein`,
`srf_rock_garden`, `srf_rock_desert`, `srf_rock_ice`, `srf_rock_lava`,
`srf_ground_garden`, `srf_ground_desert`, `srf_ground_ice`, `srf_ground_lava`(바닥 타일, 512×512, 이어 붙여도 이음새 없음, 불투명),
`relic_star_map`, `relic_crystal_core`, `relic_idol`, `relic_gear`, `relic_seed`, `relic_mask`, `relic_tablet`, `relic_compass`.
`assets/icons/`: `act_land`(착륙 탐사 버튼), `menu_relic`(도감 유물 탭) — 기존 아이콘과 같은 크기·화풍.

코드는 그림이 없어도 동작해야 한다(`Sprites.draw`가 false면 도형으로 대체). 그림 파일이 들어오면 그대로 쓰인다.

## 8. 유물 (도감 새 탭)

8종: 고대 성도(`star_map`), 수정 핵(`crystal_core`), 외계 신상(`idol`), 고대 톱니(`gear`), 화석 씨앗(`seed`), 의식 가면(`mask`), 석판(`tablet`), 중력 나침반(`compass`).
도감에 `CodexTab.relics` 탭을 더한다. 계정 단위(환생 뒤에도 남음). 한 줄 설명 문구가 있다. 새 유물은 기존 도감 토스트로 알린다.
8종 모두 모으면 도감 마일스톤 보상 한 줄(기존 마일스톤 방식을 따른다).

## 9. 통계 이벤트

`surface_start`(값: 행성 종류 index), `surface_end`(값: 0=귀환, 1=산소, 2=격추). 서버 허용 목록에 이름을 더하는 새 마이그레이션 파일
`supabase/migrations/20261111000000_starset_events_v3.sql`(v2를 기준으로 두 이름만 추가). 배포는 오케스트레이터.

## 10. 범위 밖

폐우주선 탐험, 차량 개조·업그레이드, 탐사 순위표, 다른 사람과 함께 하기.
