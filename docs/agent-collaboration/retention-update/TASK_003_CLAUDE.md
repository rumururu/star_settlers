# TASK 003 — 첫 5분의 재미 (워커 A, 먼저)

공통 규칙: `COMMON_RULES.md` (먼저 읽을 것).

## 근거
설치 169명 중 대부분이 첫날 한 번만 플레이(`PIPELINE_STATE.md`). 첫 세션 안에 "이 게임 재밌다/더 하고 싶다"를 줘야 한다.
현재 스토리(`lib/game/missions.dart` `storySteps`): 소행성 3 → 해적 3 처치 → 식민지 1 → 함선 강화 → 승무원 → 임무 → 정거장 2 → 개발도 100% → 워프.

## 먼저 측정
`test/support/progression_bot.dart`(밸런스 봇)로 새 게임 0~10분 사이 각 스토리 단계 도달 시각, 첫 승무원 시각, 첫 ★3 승무원 시각을 재서 결과에 표로 남긴다(수정 전/후).

## 구현
1. **3분 안의 확실한 보상**
   - 해적 3 처치 단계 완료 직후(또는 3분 안 어느 쪽이든 먼저) **★3 승무원 1명 확정 지급**(연출: 미나 대사 + 승무원 카드 공개 연출). 이미 있으면 중복 지급 금지(프로필/월드 플래그).
   - 첫 항성계에서 **미니 두목 '해적 부두목'** 1회 등장: 시작 함선으로 잡을 수 있는 체력, 처치 시 큰 보상(크레딧 + **함선 무기 +1 무료**, 화면에 "무기 Lv.2!" 같은 체감 연출). 처치 → `mini_boss_kill` emit. 등장 시점: 식민지 첫 정착 직후 또는 4분 경과 중 먼저. 기존 두목/현상수배 코드(`world.dart` boss/bounty) 재사용.
2. **항상 보이는 '다음 목표' 1개**
   - HUD에 짧은 목표 칩: 아이콘 + 한 줄 + 진행도(예: "화성 정착까지 광석 12개", "해적 2/3"). 스토리 단계 중에는 스토리 목표, 스토리가 끝나면 규칙 기반 다음 목표(살 수 있는 식민지 레벨업 / 다음 항성계 개발도 / 비어 있는 건물 슬롯 / 승무원 배치 등)를 우선순위로 고른다. 목표 계산은 `lib/game/`의 순수 함수(`NextGoal`)로 두고 단위 테스트.
   - 이미 HUD에 스토리/임무 카드가 있으면 **새로 만들지 말고 그것을 확장**한다(중복 UI 금지). 탭하면 해당 대상 쪽으로 기존 안내 화살표.
   - 목표 달성 시 짧은 완료 연출 + `goal_done`(value=목표 종류 번호) emit.
3. **세로 HUD 항성계 배지 글자 크기** (gameplay-depth TASK 007 후속): `test/landscape_layout_test.dart:272` 실패 6건(세로 ko/en/de, 4.0~6.5 < 10)을 레이아웃 수정으로 해결. 게이트 완화 금지. 새 목표 칩도 이 HUD 겹침 게이트(`hudRects`)를 통과해야 한다(필요하면 `hud-goal` 키 추가해 검사 대상에 포함).

## 수용 기준
- 봇: 새 게임에서 ★3 승무원 획득 ≤ 3분, 미니 두목 등장 ≤ 4분·시작 함선으로 처치 가능(헤드리스 전투 시뮬 `tool/fight_sim_test.dart` 방식), 0~30분 봇 실행 내내 목표가 비어 있는 프레임 0.
- 기존 밸런스 테스트(`test/balance_test.dart`) 통과 — 기대값을 바꿔야 하면 이유를 결과에 적고 최소로.
- 전체 테스트 실패 0 (위 6건 포함).
