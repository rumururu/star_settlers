# TASK 004 — 다시 올 이유 (워커 A, 003 다음)

공통 규칙: `COMMON_RULES.md`.

## 근거
70%가 출석 보상을 한 번도 안 받음. 출석 팝업은 타이틀 화면에서, **저장이 있을 때만** 뜬다(`lib/main.dart:139` `_dailyLogin`). 첫날 한 번 하고 나간 사람은 출석 보상을 본 적이 없다.
젬 출석 보상은 서버가 연속일로 계산한다(`loginRewards` [5,5,10,10,15,20,50], `starset_login_gems`) — 젬 액수는 바꾸지 않는다.

## 구현
1. **7일 출석 달력**: 기존 AlertDialog를 7칸 달력 패널로 교체. 오늘 칸 강조, 지난 칸 체크, 미래 칸은 보상 미리보기. 젬(서버 값) 외에 클라이언트 보상을 날짜별로 추가: 2일 광석, 3일 ★2 승무원, 5일 크레딧 묶음, **7일 출석 전용 함선 스킨**(기존 스킨 색 바꾸기 구조 `lib/game/cosmetics.dart` 재사용, 새 색 조합 1개 — 상점 판매 안 함). 7일 이후는 순환하되 스킨은 한 번만(이후엔 ★3 승무원).
   - 첫날 플레이어도 받게: **게임 화면 안에서도** 열림 — 첫 세션은 스토리 2단계(해적 처치) 완료 후, 이후에는 게임 진입 시 받을 보상이 있으면. 타이틀에서 이미 받았으면 다시 안 뜸. `calendar_open`(value=달력 칸) emit.
2. **내일 보상 미리보기**: 일시정지 메뉴와 타이틀에 "내일 접속: ★3 승무원" 같은 작은 카드. 앱이 백그라운드로 갈 때 다음 날 보상 알림을 예약(기존 `lib/services/notifications.dart`의 `scheduleReturn` 패턴, 알림 설정 꺼져 있으면 예약 안 함, 문구 10개 언어).
3. **승무원 원정**: 배치되지 않은 승무원을 1h/4h/8h 원정에 보낸다(동시 2개, 함대 사령관 패스 보유 시 3개). 앱을 꺼도 실제 시간으로 진행(시계 되돌리기 방지: 기존 `dayKey` 검사 방식 참고). 귀환 보상 = 광석·크레딧(현재 항성계 배율) + 승무원 경험치, 8h는 낮은 확률로 젬(`earnGems('play', …)`)과 희귀 승무원. 완료 시 로컬 알림. 승무원 패널(또는 기존 승무원 화면)에 '원정' 탭/버튼, 남은 시간 표시, 수령 연출. `expedition_start`(value=시간), `expedition_claim` emit.
   - 원정 중인 승무원은 배치·해고 불가. 은하 명예(환생) 때 처리 규칙 정해서 결과에 적기.
