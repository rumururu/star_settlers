## 구현 내용

- 태양계 인덱스 0은 특성 없음. 게임 로직은 UI의 항성 그림 프로필을 import하지 않는다.
- 배율은 기존 배율에 곱한다. 해적 소굴의 일반 스폰 간격 ×0.7은 반복 스폰과 항성계 전환·불러오기 시 첫 대기에도 적용된다. 현상금은 ×1.5다.
- 풍부한 광맥은 식민지 광석 ×2와 소행성 광석 드롭 ×1.5다. 기존 정수 반올림과 픽업 분할 방식은 유지한다.
- 항성 플레어는 식민지 크레딧 ×1.25, 식민지 돔·연결된 공유 방어막 재생 ×0.5다. 정거장 생산과 정박기 내구도 수리에는 적용하지 않는다.
- 이온 성운은 기존 과학자·내 행성 배율 계산 뒤 미사일·실드·부스트 쿨타임에 ×0.7을 곱한다. 식민지·정거장 포탑 탄 피해는 ×0.7이다. 별도 헤이븐 레이저와 자동 드론 주기는 유지한다.
- 중력 우물은 최고 속도 ×0.85, 현상금·두목 격파·습격 방어·게시판 임무의 크레딧 보상 ×1.3이다. 기존 공용 보상 배율에서 `baseRewardMul`을 분리해 크레딧 팩·내 행성 선물·소행성 크레딧 드롭까지 부풀지 않도록 했다. 젬·광석 보상은 유지한다.
- 교역로는 표시되는 시장 가격과 실제 판매 수령액 모두 ×1.3이다. 기존 이벤트 선택의 습격 확률도 ×1.3이다. 식민지가 있고 진행 중 습격·상인이 없으면 2/5 → 0.52, 상인만 진행 중이면 2/4 → 0.65다. 이벤트 간격 90~150초와 동시 이벤트·습격 중복 제한은 유지한다. 따라서 실제 시간당 습격 수는 이벤트 점유와 식민지 상태에도 영향을 받는다.
- 원격 저장의 `ic`·`io`는 기존처럼 특성 적용 전 기초 수입이다. `SectorSave.creditRateAt(sector)`·`oreRateAt(sector)`가 해당 항성계 특성을 적용한다. 크레딧에서는 저장된 정거장 기초 수입을 분리해 식민지 부분만 증폭한다. 기존 저장도 별도 마이그레이션 없이 같은 효과를 받는다. 원격 강화·재방문·저장 후 로드·오프라인 수입에 이중 배율이 생기지 않는다.
- 현재 식민지와 원격 식민지의 수입 표시, 항성계 패널의 원격 합계에 같은 특성을 반영했다. 기존 원격 수입의 승무원·보급 범위 규칙은 유지했다.
- 도착 시 `traitSeen_<sector>` 카운터로 미나가 항성계별 한 번 안내한다. 같은 특성인 다른 항성계에서도 각각 안내하며, 카운터는 기존 저장 구조로 보존된다.
