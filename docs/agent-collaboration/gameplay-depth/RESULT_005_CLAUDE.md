# RESULT 005 — 대규모 침공 (Claude 워커)

식민지가 3개 이상인 항성계에 **예고된 대규모 침공**을 넣었다. 흐름은 경보 20초 → 파도 3번(25초 간격) → 3파에 침공 지휘함 → 90초 안에 전멸하면 승리, 넘기면 퇴각이다. 수치는 과제 그대로다.
`flutter gen-l10n`, `dart analyze lib test`(이슈 0), `flutter test --no-pub`(**481개 모두 통과** = 이전 456 + 새 25)를 실행했다. 커밋과 기기 실행은 하지 않았다.

## 테스트 (`test/invasion_test.dart`, 25개)
- 식민지 2개면 420초가 지나도 침공이 없다. 식민지 3개면 299초에는 없고 300초에 경보가 울리며 미나 경고가 나온다. 20초 뒤 1파가 나오고, 2파와 3파는 각각 25초 간격이다(틱 단위로 재서 ±0.06초). 파도마다 마릿수는 `invasionWaveSize(threat, sector)`와 같고 3파는 +1(지휘함)이다. 등장 위치는 침공 방향 ±0.5rad, 본거지에서 2300 이내다. 지휘함은 1기이고 습격선 기반이며, 원형이 없고, 이름이 "침공 지휘함", 크기 24×1.4, `dmgScale`은 enemyDamageMul×1.5, 체력은 기본×scale×6이다. 판정 타이머는 90이다. 3파 뒤에는 더 나오지 않는다
- 파도 크기 공식: 최대 18, 태양계 ×0.6, 최소 4(`(0,0)=4`). 태양계가 아닌 항성계(sector 3)의 실제 파도에는 0.6이 곱해지지 않는다
- 경보와 진행 중에는 일반 스폰이 0이고, 결과가 나온 뒤에는 다시 스폰된다. 침공 중 습격은 150번 시도해 0회였다(대조군 >20회)
- 승리: 크레딧 증가가 `round(600×rewardMul×shipCreditMul)`이고(한 틱 생산분 오차 허용) 젬 +5, `invasions` +1, 미나 축하 대사가 나온다. 결과 표시는 8초 뒤 사라진다. 1파만 다 잡았을 때는 판정하지 않는다
- 퇴각: 남은 침공 적이 0이 되고, 보상은 `round(전체 × 처치비율)`이며 젬과 통계는 그대로다. 식민지 레벨(Lv.3)도 그대로다. 본거지를 멈추고 선장을 멀리 둔 채 실제로 90초를 돌리면 퇴각한다
- 워프하면 침공이 취소되고 침공 적이 사라지며 타이머는 300이 된다. 젬과 통계는 그대로다. 선장이 격추돼 있는 동안에는 시작하지 않고, 되살아난 틱에 시작한다. 다음 간격은 시드 6개 모두 360~480 안이고 결과 표시 중에도 줄어든다. 불러온 세계에서는 침공이 null이고 타이머는 300이다
- 위젯 10개 언어 × 360×740 / 800×360 × 경보 / 진행 / 승리 / 퇴각, 글자 1.3배: 배너가 1개 있고 문구가 `keepAll(기대값)`과 같다. 화면 안에 있고 캡틴(임무 카드 포함), 미니맵, 조이스틱, 순항, 전투 버튼, 자동 사격, 행동 버튼, 대사와 겹치지 않는다. 새로 생긴 넘침은 0이다
