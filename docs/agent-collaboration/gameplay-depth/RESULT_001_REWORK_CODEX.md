# REWORK 001 결과

지적된 두 실패를 재현하고 UI 원인을 수정했다. 정적 분석과 전체 테스트 **379개가 모두 통과**했다. 기존 테스트 기대값을 유지했으며, 헤더의 실제 위치와 잠금 버튼의 최소 크기 검증을 추가했다.

## 이번 재작업 변경 파일

| 파일 | 변경 |
|---|---|
| `lib/ui/station_panel.dart` | 상단 자원 표시의 텍스트를 `Flexible`로 제한하여 좁은 폭에서 줄바꿈 허용 |
| `lib/ui/colonies_panel.dart` | 진척 잠금 안내를 행 전체 폭을 쓰는 하단 캡션으로 이동 |
| `test/level_cap_test.dart` | 식민지·함선 잠금 버튼의 실제 화면상 폭·높이가 각각 48dp 이상인지 검증 |
| `test/colonies_panel_test.dart` | 화면 크기 변경 후 현재 항성계 헤더가 스크롤 영역 위로 밀리지 않는지, 잠금 버튼이 48dp 이상인지 검증 |
| `docs/agent-collaboration/gameplay-depth/RESULT_001_REWORK_CODEX.md` | 이 결과 기록 |

기존 작업 트리의 선행 변경은 보존했다. `game_icons.dart`, 게임 규칙, 번역, 밸런스 봇·기대 수치는 이번 재작업에서 수정하지 않았다.

## 원인과 수정

### 1. StationPanel 가로 넘침

수정 전 대상 테스트에서 360×740, 텍스트 배율 1.3 조건의 9.8px·0.791px 넘침을 재현했다. 실제 발생 위치는 강화 행이 아니라 정거장 상단의 자원·수입 표시였다. 로그의 생성 경로는 `Row ← Wrap ← Column ← Expanded ← Row ← Padding ← ListenableBuilder`였으며, 사용할 수 있는 폭은 206dp였다.

`Wrap`은 자원 표시 묶음을 다음 줄로 옮길 수 있지만, 각 묶음 내부의 `iconValue`는 텍스트 폭을 제한하지 않는 `Row`여서 긴 숫자를 감당하지 못했다. 정거장 헤더에만 적용하는 `_resource`를 두고 텍스트를 `Flexible`로 감싸 원래 글자 크기로 줄바꿈하도록 했다. 공용 아이콘 위젯과 버튼 크기는 변경하지 않았다.

### 2. 러시아어 현재 항성계 헤더 누락

잠금 안내가 행성 아이콘 옆의 좁은 열에 들어가 러시아어에서 세 줄을 차지했다. 이로 인해 목록이 길어지고, 원격 식민지로 스크롤한 위치가 가로 화면 전환 후에도 유지되면서 상단의 `Вы здесь`가 화면 위로 밀렸다.

임시 진단으로 수정 전 러시아어 세로 화면의 스크롤 최대값과 실제 이동값이 71dp이며, 가로 전환 후에도 71dp가 유지되는 것을 확인했다. 잠금 안내를 아이콘 옆 열에서 빼고 행 전체 폭의 하단 캡션으로 옮겼다. 같은 조건의 세로 스크롤 최대값은 11dp로 줄었고, 전환 후 헤더 위치 검증도 통과했다. 스크롤 위치를 강제로 초기화하거나 번역 문구를 잘라내지 않았다.

진단용 출력은 제거했다. 기존의 헤더 존재·현재/원격 식민지·잠금 해제·MAX 구분 기대값을 그대로 유지하고 위치·크기 검증만 추가했다.

## 검증

| 명령 | 결과 |
|---|---|
| 수정 전 `flutter test --no-pub test/level_cap_test.dart test/colonies_panel_test.dart --reporter expanded` | 17 통과, 지시서의 2건 실패 재현 |

대상 위젯 테스트는 360×740 / 800×360, 텍스트 배율 1.3을 사용한다. 내 식민지 패널은 10개 언어, 식민지·함선 패널의 진척 잠금/기존 고레벨 저장/MAX 구분은 한국어 조건에서 확인했다. 추가한 크기 검증은 변환 후 화면 좌표를 사용하므로 `FittedBox` 안의 원래 크기만 확인하는 검사가 아니다.
